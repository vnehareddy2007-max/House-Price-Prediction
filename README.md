#  California House Price Prediction

## Overview

This project predicts California house prices using machine learning regression models. It covers the complete ML workflow from data preprocessing and exploratory data analysis to model training and evaluation.

## Dataset

- California Housing Dataset

## Workflow

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training
- Hyperparameter tuning
- Model evaluation

## Models Used

- Linear Regression
- Random Forest Regressor
- Random Forest + GridSearchCV

## Evaluation Metrics

- R² Score
- RMSE
- MAE
- MSE

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
